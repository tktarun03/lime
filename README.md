# LIME — workout tracker

A minimalist, dark, neon-lime workout PWA. Plans built from your goal,
level, equipment and time; a full-screen player with rest timers and a
3-2-1 countdown; progress, streaks and records. **Everything stays on your
phone** — no account, no server.

- Open it, add it to your Home Screen, and follow the set-up.
- Just looking? Tap **Try demo mode** on the first set-up screen.
- Back up from Settings → Back up to a file.

Run locally: `python3 -m http.server 8765` then open http://localhost:8765.
Developers: start with [AGENTS.md](AGENTS.md).
